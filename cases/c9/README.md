# C9 inputs (frozen 2026-10-12)

`docs.jsonl` (not yet in git, see below): the 476 German documents of the `test` split of
`gretelai/synthetic_pii_finance_multilingual` (revision `7b844d167385`),
sorted on Gretel's `index`, with their gold spans exactly as Gretel ships
them (offsets, label, covered text). Written by `bench/c9/freeze.py`;
hashes, ids, the 40 gold audit ids and the train label counts in
`manifest.json`; design in `plan/c9.md`, label mapping in
`reference/c9/labels.json`.

The texts and the labels are synthetic, generated by a language model
(Gretel.ai, Apache-2.0, see `LICENSE`). Names,
addresses and numbers in them are invented; the gold itself is a model
output and is audited on 40 documents before any C9 number is published.

Why `docs.jsonl` is not committed yet: two of the invented documents
contain API keys in real provider formats (a Slack bot token and AWS key
ids, all made up by the generator), and GitHub's push protection rejects
them. Until a maintainer clears them as test data, the file is rebuilt with
`python bench/c9/freeze.py --dir .cache/c9` (it lands in `.cache/c9/` and
must match `docs_sha256` of `manifest.json`); the runs read it from the
workstation's data folder. Nothing else changes: the same 476 rows, hash
for hash.
