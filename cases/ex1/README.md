# Test cases ex1 (slot extraction)

Frozen inputs of the ex1 family: find the slots (dates, places, names and so
on) in a short spoken command. Gold slots come from the MASSIVE annotation,
so the reference is the dataset's own (`reference/ex1/`), not a judge.

Frozen on 2026-10-09 by `bench/freeze-route-ex.mjs` from the same MASSIVE 1.1
tarball as route1 (source, hash, licence and attribution in
[`cases/route1/README.md`](../route1/README.md)).

## Files

| file | what |
|---|---|
| `sample-de.jsonl`, `sample-en.jsonl` | 1,000 test utterances per language, the same ids in both: `id`, `utt`, `annot_utt`, `scenario`, `intent`, `slots` (`type`, `text`) |
| `slot-types.json` | the 53 slot types that occur in the test split of de-DE and en-US, the sample seed and the quota per scenario |
| `slot-labels.json` | the label text every arm gets per slot type (underscores replaced by spaces), generated by `bench/build-route-ex.mjs` |

## Sample

- Seed 20261009. The 2,974 en-US test ids are shuffled once with mulberry32
  (the generator of `bench/normalize.mjs`), then taken in that order until
  every scenario has its quota.
- Stratified by scenario: quota proportional to the scenario's share of the
  test split, rounded by largest remainder, 1,000 in total.
- The German sample uses the same ids.

## Gold slots

Parsed from `annot_utt` with the regex `\[([^\]:]+?) : ([^\]]+?)\]`, for
example `wecke mich in [date : dieser woche] um [time : fünf uhr] auf`. de:
941 slots, en: 937. 335 utterances per language have no slot. Every gold
value occurs verbatim in `utt`.

The slot type list is derived from the data, nothing is hand-written: every
type that occurs in the test split of either language. The MASSIVE dataset
card lists 55 types overall; two of them do not occur in these test files.

MASSIVE slot annotation was localised by translators, so some German slots
are translations of the English value rather than a fresh annotation.
